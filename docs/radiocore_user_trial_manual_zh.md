# Heltec RadioCore 用户试用手册

本文供 RadioCore 样机试用人员使用，适用于当前项目的 RC32、RC52 和 RCC6
Companion Radio 固件。本文重点说明开机、按键、页面导航、BLE/USB 连接和主要功能验收，
不涉及编译、烧录和硬件开发。

更完整的页面说明见 [MeshCore LVGL UI 用户操作手册](./user_manual_zh.md)。

## 1. 试用前确认

### 1.1 确认样机型号和固件

| 样机 | 对应固件名称 | GPS | Compass | P0/P1 导航 |
| --- | --- | --- | --- | --- |
| RC32 | `heltec_radio_core_rc32_companion_radio_ble` 或 `_usb` | 支持 | 支持 | 支持 |
| RC52 | `heltec_radio_core_rc52_companion_radio_ble` 或 `_usb` | 支持 | 当前固件不启用 | 支持 |
| RCC6 | `heltec_radio_core_rcc6_companion_radio_ble` 或 `_usb` | 不支持 | 不支持 | 不支持 |

页面会随样机能力变化。某个页面没有出现时，先核对样机和固件名称，不要直接判断为故障。

### 1.2 安全事项

1. 开机前安装与设备频段匹配的 LoRa 天线。
2. 不要在未接天线时发送消息、Advert 或进行长时间射频测试。
3. 首次启动后先设置正确的 `Region`，并遵守当地无线电法规。
4. 位置分享会向 Mesh 网络发布位置；不需要时关闭 `location share`。
5. 恢复出厂会清除设备配置、联系人和频道，试用期间不要随意执行。

### 1.3 建议准备

- 一根数据 USB 线和稳定电源。
- 安装 MeshCore Companion 客户端的手机或电脑。
- 两台频段、区域和无线参数一致的 MeshCore 设备，用于收发测试。
- 在室外或窗边测试 GPS。
- 测试结果记录表，建议同时记录固件版本和样机编号。

## 2. RadioCore 操作方式

### 2.1 USER 按键

RC32、RC52 和 RCC6 的 USER 按键使用相同手势：

| 操作 | 功能 |
| --- | --- |
| 单击 | 下一项 / 下一个图标 |
| 双击 | 返回或关闭最上层弹窗 |
| 三击 | 打开当前页面的操作菜单 |
| 长按约 1 秒 | 确认、进入或切换当前选中项 |

双击和三击应在约 350 ms 的多击窗口内完成。屏幕刚被自动关闭时，第一次操作可能只负责
唤醒屏幕，需要再操作一次。

### 2.2 RC32/RC52 的 P0、P1

RC32 和 RC52 通过 TCA6408A 扩展 P0/P1 导航输入：

| 输入 | LVGL 功能 | 导航界面 | Screen 页面 |
| --- | --- | --- | --- |
| P0 | `PREV` | 上一个图标 | 上一个选中项 |
| P1 | `NEXT` | 下一个图标 | 下一个选中项 |

P0/P1 为低电平有效，每次从释放状态切换到按下状态只触发一次。保持按下不会连续翻页。
如果样机使用保持式拨码开关，必须先拨回 OFF，再次拨到 ON 才会产生下一次操作。

P0/P1 只负责移动选择，确认仍使用 USER 按键长按。

### 2.3 最常用操作

| 目的 | 操作 |
| --- | --- |
| 移到下一项 | P1，或 USER 单击 |
| 移到上一项 | P0；RCC6 可继续单击 USER 循环选择 |
| 确认或进入 | USER 长按 |
| 返回 | USER 双击 |
| 打开页面操作菜单 | USER 三击 |
| 打开页面导航 | 在普通页面根层双击 USER |

弹窗、下拉框或输入界面打开时，返回会优先关闭最上层。可能需要再次返回才能打开页面导航。

## 3. 首次开机快速流程

### 3.1 开机检查

1. 安装 LoRa 天线并接通电源。
2. 等待启动画面结束，确认进入 `Home`。
3. 确认屏幕无花屏、明显偏色、持续闪烁或死机。
4. 记录 `Home` 上显示的节点 ID、连接状态和配对 PIN。
5. 双击 USER 打开导航，再操作 P0/P1 或 USER，确认高亮图标可以移动。

若设备长期停在启动画面，先断电重启一次；仍无法进入 `Home` 时，记录停留画面和串口日志。

### 3.2 设置 Region

1. 在普通页面双击 USER，打开页面导航。
2. 移到 `System`，长按 USER 进入。
3. 移到 `Region`，长按打开选项。
4. 选择符合当地法规和样机射频版本的区域。
5. 长按确认并返回。

两台设备进行通信测试时，Region、频率、带宽和扩频因子必须一致。

### 3.3 连接 Companion

BLE 固件：

1. 确认使用文件名带 `_ble` 的固件。
2. 在手机上打开蓝牙和 MeshCore Companion 客户端。
3. 在客户端扫描并选择当前 RadioCore。
4. 配对时使用 `Home` 页面显示的 PIN；当前试用构建默认 PIN 通常为 `123456`。
5. 连接成功后，`Home` 应显示 `Connected`。

USB 固件：

1. 确认使用文件名带 `_usb` 的固件。
2. 使用支持数据传输的 USB 线连接电脑或主机。
3. 在 Companion 客户端选择对应串口设备。
4. 连接成功后检查 `Home` 的连接状态。

BLE 和 USB 是 Companion 连接方式，不是 LoRa 开关。Companion 未连接时，设备仍可参与 LoRa
Mesh 通信。

## 4. 页面说明

### 4.1 Home

用于快速查看节点和 Companion 状态：

- `ID`：本机节点 ID。
- `MSG`：未读消息数量。
- `Pin`：Companion 配对 PIN。
- `Connected`：Companion 已连接。
- 顶部电池图标：电池电量估算。

### 4.2 Recent

显示最近听到的节点 Advert。收到其他设备的 Advert 后，应出现节点名称和最近听到时间。
这里不是完整聊天记录页面。

### 4.3 Radio

显示频率、SF、BW、CR、TX、RSSI、SNR 和噪声底等无线状态。三击 USER 打开操作菜单，
可选择 `send message` 或 `send advert`。

### 4.4 GPS

RC32 和 RC52 提供 GPS 页面。常见状态：

| 状态 | 含义 |
| --- | --- |
| `gps off` | GPS 已关闭 |
| `gps sleep` | GPS 已启用，但当前没有持续定位需求 |
| `no fix` | 已启动，尚未定位 |
| `fix` | 已获得有效位置 |
| `can't access gps` | 无法访问 GPS 硬件 |

首次定位应到室外开阔区域，冷启动可能需要数分钟。打开 `location share` 后，Advert 可以携带
位置；试用结束后应根据隐私需要关闭。

### 4.5 Compass

当前仅 RC32 固件启用 Compass。页面应显示蓝色和红色指针、航向角和校准质量。若长期显示
`Starting...`，重新启动设备并检查传感器连接。

校准时远离磁铁、扬声器、大电流导线和大块金属，缓慢转动设备并做多方向“8”字运动，
直到页面提示校准成功。

### 4.6 Find Friend

RC32 具备 GPS 和 Compass，适合完整试用 Find Friend：

1. 本机先获得 GPS fix。
2. 完成 Compass 校准。
3. 选择带有效位置的联系人，或输入 waypoint。
4. 确认方向指针和距离随设备位置、朝向变化。

RC52 当前没有启用 Compass，因此即使能选择目标，也不应把相对方向指针作为完整验收项。

### 4.7 System

用于设置 Region、屏幕关闭时间、Companion/Bluetooth，以及执行清除或恢复操作。硬件和固件
支持时，还会显示蜂鸣器及音量控件。
带 `Factory reset`、清除联系人或清除频道含义的操作会删除数据，试用时应谨慎确认。

## 5. 推荐试用项目

### 5.1 显示和输入

1. 冷启动和热重启各进行 3 次。
2. 检查启动画面、颜色、背光和页面刷新。
3. 打开导航，使用 P0/P1 上下翻图标。
4. 进入 `System`，使用 P0/P1 上下移动选中项。
5. 验证 USER 的单击、双击、三击和长按。

通过标准：无死机、乱跳、连续误触；一次 P0/P1 动作只移动一项。

### 5.2 BLE 或 USB 连接

1. 连续连接、断开 3 次。
2. 连接后保持运行至少 10 分钟。
3. 让屏幕自动关闭，再从客户端读取状态或发送操作。

通过标准：能重新连接，屏幕关闭不导致 Companion 链路异常，Home 状态与实际连接一致。

### 5.3 LoRa 收发

1. 两台设备使用相同 Region 和无线参数。
2. 设备 A 执行 `send advert`。
3. 在设备 B 的 `Recent` 检查是否出现 A。
4. 从 Companion 或 `send message` 向 B 发送消息。
5. 检查 B 的提示、消息预览和未读数量。
6. 交换 A、B 角色再测试一次。

`Queued` 只表示消息进入发送队列，不等于对方已经收到。验收必须以接收端实际显示为准。

### 5.4 GPS 和位置分享

仅 RC32/RC52：

1. 在室外打开 GPS，等待 `fix`。
2. 检查卫星数、经纬度、海拔和速度是否合理。
3. 打开 `location share`，发送 Advert。
4. 在另一台设备或 Companion 中检查位置更新。
5. 关闭位置分享，确认设置状态保存。

### 5.5 Compass 和 Find Friend

仅 RC32：

1. 完成指南针校准。
2. 将设备水平旋转一周，检查指针连续变化且颜色正常。
3. 设置一个已知方向的 waypoint。
4. 检查 Find Friend 的方向和距离是否基本合理。

指南针在室内金属桌面、车辆附近或强磁场中出现偏差不一定是固件故障，应换到开阔环境复测。

### 5.6 长时间运行

1. 保持 Companion 连接和 LoRa 接收 2 小时以上。
2. 期间反复打开导航、切换页面并让屏幕自动关闭。
3. GPS 型号可连续定位 30 分钟。
4. 记录重启、卡死、明显发热、异常耗电或连接丢失。

## 6. 常见问题

### 6.1 P0/P1 没有反应

- 确认样机是 RC32 或 RC52，RCC6 当前不支持该扩展输入。
- 若是保持式拨码，先回到 OFF，再拨到 ON。
- 检查开机日志中是否出现 `TCA6408A ready=1`。
- 若显示 `ready=0`，记录样机编号和完整启动日志。

### 6.2 P0/P1 方向相反

当前定义为 P0 上一项、P1 下一项。若样机丝印或物理排列与此相反，请在反馈中附上正面照片并
说明期望方向，不要仅描述“上下反了”。

### 6.3 无法确认选中项

P0/P1 只移动焦点。选中目标后，需要长按 USER 约 1 秒确认。

### 6.4 BLE 搜不到设备

- 确认烧录的是 `_ble` 固件，而不是 `_usb` 固件。
- 确认 `System` 中 Companion/Bluetooth 没有关闭。
- 关闭手机系统蓝牙再重新开启，并重启 RadioCore。
- 删除手机上旧的配对记录后重新扫描。

### 6.5 两台设备不能通信

- 检查两台设备是否都安装天线。
- 检查 Region、频率、SF、BW 和 CR 是否一致。
- 先在近距离、无遮挡环境测试。
- 检查 `Radio` 页面 RSSI/SNR 是否有变化。

### 6.6 GPS 长时间 no fix

- 移到室外开阔区域，天线朝上静置数分钟。
- 确认 GPS 已打开，而不是 `gps off` 或 `gps sleep`。
- 冷启动时间通常明显长于热启动。
- RC52 与 RC32 的 GPS 硬件不同，应分别记录现象。

### 6.7 Compass 一直 Starting

- 当前只把 Compass 作为 RC32 的验收项目。
- 重启后再次进入页面，等待数秒。
- 检查传感器扩展板和连接。
- 附上启动日志以及 Compass 页照片反馈。

## 8. 快速验收清单

- [ ] 开机正常进入 Home，屏幕颜色正常。
- [ ] 已安装正确频段的 LoRa 天线。
- [ ] Region 设置正确。
- [ ] USER 单击、双击、三击、长按正常。
- [ ] RC32/RC52 的 P0/P1 可上下移动且无连续误触。
- [ ] BLE 或 USB Companion 可以连接和重新连接。
- [ ] 两台设备可互收 Advert。
- [ ] 两台设备可互收消息。
- [ ] RC32/RC52 可获得 GPS fix。
- [ ] RC32 Compass 可启动、校准且颜色正常。
- [ ] RC32 Find Friend 的方向和距离基本合理。
- [ ] 自动熄屏和唤醒正常。
- [ ] 连续运行期间无死机、异常重启或明显发热。
- [ ] 已填写样机、固件、环境和复现信息。
